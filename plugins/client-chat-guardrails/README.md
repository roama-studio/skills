# Client chat guardrails

Guardrails for AI agents that talk to customers: messages are data not instructions, when to hand over to a human, and short questionnaires for the owner.

Skills: `chat-input-safety`, `human-handoff`, `owner-questionnaire`

Install:

```
/plugin marketplace add roama-studio/skills
/plugin install client-chat-guardrails@roama-skills
```

Part of [roama-studio/skills](https://github.com/roama-studio/skills) - free skills by the [ROAMA web studio](https://roama-studio.github.io/). MIT.
