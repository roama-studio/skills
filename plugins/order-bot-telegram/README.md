# Telegram order bot (PHP)

A Telegram bot for orders and bookings on ordinary shared PHP hosting: one webhook file, no database, orders to the owner's Telegram and a Google Sheet.

Skills: `order-bot-telegram`

Install:

```
/plugin marketplace add roama-studio/skills
/plugin install order-bot-telegram@roama-skills
```

Part of [roama-studio/skills](https://github.com/roama-studio/skills) - free skills by the [ROAMA web studio](https://roama-studio.github.io/). MIT.
