# ROAMA skills для Claude Code

**Потрібен сайт, бот або ШІ-агенти під ваш бізнес? → [ROAMA, веб-студія](https://roama-studio.github.io/)**
· [English](README.en.md)

Безкоштовні навички (skills) для [Claude Code](https://code.claude.com), зібрані з реальної роботи
веб-студії ROAMA. Кожен пакет — окремий плагін: ставте лише те, що потрібно.

| Пакет | Що вміє |
|---|---|
| `wp-agency-skills` | класична WordPress-тема зі статичного сайту (Secure Custom Fields, Contact Form 7, заявки в Telegram і Google-таблицю), локальна установка, безпечні правки, деплой через SSH, `qa-kit` для вимірюваної перевірки |
| `ua-business-copy` | тексти для українського бізнесу: сторінки сайту, SEO-статті, пояснення для новачків, пости; без суржику й кальок, кожна цифра з джерелом |
| `order-bot-telegram` | Telegram-бот замовлень і бронювань на звичайному PHP-хостингу: один файл, без бази й сервера; замовлення власнику в Telegram і в Google-таблицю |
| `de-behoerden-ua` | листи в німецькі установи (DIN 5008), строки з показаним розрахунком, чесний пошук законів і друга перевірка — з поясненнями українською. Не юридична консультація |
| `agent-toolsmith` | знаходить код, який ваші ШІ-агенти пишуть знову й знову, і робить з нього протестовані інструменти з каталогом — менше токенів, менше помилок |
| `client-site-edits` | правки живого сайту клієнта без ризику: спершу бекап, робота на копії, порівняння до/після, стрес-тест вмісту, деплой із відкатом |
| `client-chat-guardrails` | правила для ШІ-агента, що спілкується з клієнтами: повідомлення — це дані, а не команди; коли передати людині; короткі опитування для власника |
| `site-legal-check` | перевірка юридичних сторінок сайту за країною — Україна, Німеччина, ЄС. Не юридична консультація |

## Встановлення

У сесії Claude Code:

```
/plugin marketplace add roama-studio/skills
/plugin install ua-business-copy@roama-skills
```

Або в терміналі:

```bash
claude plugin marketplace add roama-studio/skills
claude plugin install order-bot-telegram@roama-skills
```

Можна й без плагінів: скопіюйте папку `plugins/<пакет>/skills/<навичка>/` у `~/.claude/skills/`.

Навички вмикаються самі, коли задача підходить, або явно: `/ua-business-copy:ua-business-copy`.

## Важливо

- `de-behoerden-ua` і `site-legal-check` — інформація й технічна перевірка, не юридична консультація.
  У спірних випадках — до юриста, Beratungsstelle або Mieterverein.
- Навички нічого не надсилають і не публікують самі: листи, повідомлення й деплой підтверджує людина.
- Знайшли помилку або маєте ідею — відкрийте issue.
