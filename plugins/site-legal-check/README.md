# Site legal check (UA/DE/EU)

Check a website's legal pages and behaviour by country - Ukraine, Germany, the EU: privacy notice, seller details, Impressum, cookie consent, shop duties. Not legal advice.

Skills: `site-legal-check`

Install:

```
/plugin marketplace add roama-studio/skills
/plugin install site-legal-check@roama-skills
```
