# WordPress agency skills

Classic WordPress themes from a static site (SCF + Contact Form 7 + leads to Telegram/Google Sheets), local install, safe edits of existing sites, deploy over SSH, and qa-kit: measured QA of themes and sites.

Skills: `wp-classic-theme`, `wp-deploy`, `wp-edits`, `wp-local-install`, `wp-theme-qa`

Install:

```
/plugin marketplace add roama-studio/skills
/plugin install wp-agency-skills@roama-skills
```

Part of [roama-studio/skills](https://github.com/roama-studio/skills) - free skills by the [ROAMA web studio](https://roama-studio.github.io/). MIT.
